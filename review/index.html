Known limitations

Line coverage does not equal fixture coverage

Sportsbooks and prediction markets may not price lower-tier or regional LoL. A blank probability is intentional, not a claim of even odds. Community performance datasets such as Oracle's Elixir are research context, not a substitute betting line; their documented coverage/update cadence does not establish an auditable probability for every Hotspawn match. No such fallback model is currently used.

OddsPapi LoL API coverage and key requirement · Polymarket LoL market page · Oracle's Elixir historical data

Optional odds API key is not provisioned in this repository

Without external odds-feed access, automated updates can publish only match inventory. All picks remain unresolved until sourced market prices are available. No key is stored in code or Git history.

OddsPapi API documentation and signup

Match page structure may change

The collector checks Hotspawn's match links and fixture IDs, but depends on public lobby markup for team alt labels and an active LoL marker. A changed page fails closed and preserves the previous snapshot.

Hotspawn public lobby · Pick'em API route index

No start time or best-of format unless source-confirmed

Hotspawn may render times without a timezone or structured metadata. Such values are intentionally left blank. We do not infer the timezone from a browser locale or tournament convention.
