Access notes

  • All endpoints above are public and unauthenticated; the pipeline sends an identifying user agent and rate-limits itself.
  • Not used: Hotspawn crowd pick percentages, Hotspawn tiers/points, any third-party prediction article, or any screen-scraped bookmaker page that forbids automated access.
  • Leaguepedia/Fandom was evaluated for results history but returned ratelimited from CI, and Liquipedia returned HTTP 403/406 for automated access, so neither is used as a live input. This is recorded on the review page.

Independent line generation. Fixture list from Hotspawn Play. Market prices from public, citable exchange/bookmaker APIs. Hotspawn's crowd “% picked” is never used to set a probability.
