Sources and methodology

This project tracks Hotspawn's LoL pick'em fixture inventory, then checks independent market prices. It never treats Hotspawn crowd-pick shares as the match probability.

Source register

Every displayed match links to its Hotspawn match page. A probability is shown only when an external, two-outcome match-winner line can be matched to the same teams. For odds, provider data are attributed to the provider and the named operator source where returned. Rows without a confirmed operator market have no probability.

How a market becomes a pick

  1. The scheduled collector downloads Hotspawn's public lobby and requires match links, two labeled team names, and a positive LoL tab/game marker. It validates extracted fixture IDs against Hotspawn's Pick'em API permalink map. It does not infer names or dates from URL slugs.
  2. If the optional OddsPapi key is configured, the collector checks a bounded upcoming fixture window (under ten days, as required by the provider's sport/date query) and requests match odds from the documented Pinnacle, bet365, and 1xBet sources. Team names must match exactly after removing case and punctuation; fuzzy mapping is not used. Matches beyond the provider query window remain unpriced until covered by a later refresh.
  3. For each active two-way operator price pair, decimal odds are converted to raw implied values (1 / decimal odds), then normalized across both outcomes so the pair sums to 100%. The dashboard averages normalized probabilities across distinct named operators, rounds to one decimal, and displays the higher-probability team as the pick. This is a market-derived estimate, not a guarantee.
  4. The source and capture timestamp accompany each priced match. If the market outcome labels, fixture identity, or odds pair are ambiguous, no probability is published. Odds may be stale or suspended; always check the linked operator for current availability and terms.

Coverage limits

  • Low-tier, regional, academy, and less-covered matches can have no bookmaker line. These remain listed but unpriced where Hotspawn inventory extraction is verified.
  • Public prediction markets such as Polymarket cover only some competitions. No market is not equivalent to 50/50.
  • Current implementation depends on Hotspawn's public lobby markup and the exposed fixture permalink endpoint. If Hotspawn changes the page or LoL tab behavior, the collector keeps the last good snapshot and publishes a failure flag rather than overwriting match data.
  • OddsPapi's documented feed requires a key. Without a configured key, the public match list may refresh but all probabilities remain blank. No API key is committed in this repository.
  • Start time, best-of format, or event title is shown only when a machine-readable source value is obtained. Otherwise it stays blank or reads “not confirmed.”
