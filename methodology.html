🏛️ Line Origination Architecture

Our forecasting engine follows a rigorous four-tiered resolution hierarchy to ensure every match listed on Hotspawn receives an objective, mathematically validated pick:

Tier 1: Multi-Bookmaker Consensus (Esportsbooks)

When commercial bookmakers offer moneyline odds on a match, we ingest decimal odds across multiple sportsbooks (Pinnacle, bet365, Betway via OddsPapi SportId=18, Market=181). We remove the bookmaker overround (vig) using proportional normalization:

P_raw(Team_i) = 1 / Odds_i
P_devigged(Team_i) = P_raw(Team_i) / Σ [1 / Odds_k]

We then take the median de-vigged probability across all active books to protect against sharp line outliers.

Tier 2: Prediction Markets (Polymarket Gamma API)

For featured international tournaments (such as Worlds 2026 and EMEA Masters), Polymarket provides real-time crowd liquidity with binary outcome pricing. We map these direct outcome share prices as external probability lines, completely independent of Hotspawn's internal crowd metrics.

Tier 3: Proprietary Elo Model (Leaguepedia Cargo API)

When commercial betting markets do not cover a match (standard for Tier-2 and regional Tier-3 leagues), we originate our own lines using an Elo rating system constructed from official competitive match records:

  • Database Query: Leaguepedia Cargo API querying the ScoreboardGames table over the trailing 180 days.
  • Base Rating & Sensitivity: Base rating 1500, K-factor = 32.
  • Expected Win Probability: E_A = 1 / (1 + 10^((R_B - R_A) / 400))
  • Bayesian Sample Shrinkage: For teams with fewer than 10 games in the database, we shrink the raw probability toward 50% according to Shrink = N / (N + 10) where N = min(Games_A, Games_B).

Tier 4: Unresolved Low-Tier Baseline (Honest 50/50)

If neither external betting lines nor historical database records exist for both teams (common in amateur 3rd divisions), the match is classified as UNRESOLVED. Rather than hallucinating or inventing odds, we assign an explicit 50.0% / 50.0% baseline and pick Team 1 nominally.
