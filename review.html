How to review this page. Every row above carries the exact source link that produced it. Open the link, check the number, and if it does not match, open an issue on the repository - the collector re-reads the source on the next scheduled run, so a corrected source fixes the row without a code change.

How to read this site. Every match listed on HotSpawn's League of Legends pick'em board gets a pick and a win probability for both teams. Probabilities come from external betting lines (Kalshi, Polymarket, Pinnacle, Bovada) or, where no book prices the match, from our own line fitted on Leaguepedia results. HotSpawn's own "X% picked" figures are never used as a probability signal.
