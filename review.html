Team-name join rules were tightened (documented change) Two matching rules changed in the results join and are flagged here for review. (1) Leaguepedia disambiguator suffixes such as "(Norwegian Team)" are stripped before matching, because they are wiki metadata rather than team names. (2) The token "academy" is no longer dropped during normalisation: dropping it conflated academy rosters with parent orgs (e.g. Babos Gaming Academy vs Babos Gaming), which are different squads. A missed join leaves a row unresolved; a wrong join would fabricate evidence, so the safer direction was chosen. source
One Leaguepedia row is dated in the future yet already carries a winner Of 23277 completed rows pulled from Leaguepedia, 0 has a kickoff time after the collection timestamp. Such rows are excluded from the Elo pass (a result cannot exist before a match is played) and are flagged here rather than silently used. source

Every ingested price is an exchange quote; none is inferred. source

All upstream collection therefore runs on GitHub Actions runners, which have full internet access. The workflow and its raw outputs are committed here so every number can be traced. source
